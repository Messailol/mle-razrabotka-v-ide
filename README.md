# DataFrameReporter

Учебный проект спринта 6 курса «Инженер машинного обучения» Яндекс Практикума.

Класс `DataFrameReporter` выполняет первичную диагностику датафрейма: выводит
размер таблицы, количество и долю дубликатов, сводную статистику, а также
количество и долю пропущенных значений.

## Установка

Создайте и активируйте виртуальное окружение, затем установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Поместите файл `payments.csv` в каталог `data/` и выполните:

```bash
python main.py
```
